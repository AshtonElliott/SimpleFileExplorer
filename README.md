# SimpleFileExplorer (SFE)
SimpleFileExplorer is an application that is meant to be used to find files on your computer within a small timeframe (less than 10 minutes).

## Why Not Use the Windows File Explorer Search Engine?

Currently, the Windows File Explorer Search Engine (WFESE) takes at least 11 minutes and 9 seconds to find a single result when searching the entire computer. This number was gathered by running a test by setting the file directory to "This PC" and search for the keyword "BERT". Once again, it took 11 minutes and 9 seconds to find a single result and around 14 minutes to find more results. More so, while the desired result was found within the 11 minutes and 9 seconds, it was only a shortcut and not the actual file itself with its true filepath.

Given the lack of accuracy and long timing from WFESE, we decided to create SFE as a more efficient alternative.
